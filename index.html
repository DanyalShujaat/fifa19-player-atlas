THE STORY BEHIND THE DATA

Statistics are the start
of the conversation.

This project turns the FIFA 19 complete player dataset into an interactive exploration of ratings, potential, position and age. I used Python to prepare the records and built a browser interface for quick comparisons. Ratings are game data, not real world scouting assessments.
